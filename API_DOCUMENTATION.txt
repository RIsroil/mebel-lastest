================================================================================
  XATO FORMATLARI
================================================================================

Barcha xatolar quyidagi formatda qaytadi:

{
  "success": false,
  "message": "xato.kodi",
  "data": null
}

Asosiy HTTP status kodlari:
  200 OK         — Muvaffaqiyatli
  201 Created    — Yangi resurs yaratildi
  204 No Content — Muvaffaqiyatli (body yo'q)
  400 Bad Request — Noto'g'ri so'rov
  401 Unauthorized — Autentifikatsiya talab qilinadi
  403 Forbidden  — Ruxsat yo'q
  404 Not Found  — Topilmadi
  409 Conflict   — Konflikt (masalan: username band)
  500 Internal Server Error — Ichki xato

================================================================================
  PAGEABLE PARAMETRLAR (umumiy)
================================================================================

Pageable qo'llab-quvvatlaydigan endpointlar uchun:
  ?page=0        — Sahifa raqami (0 dan boshlanadi)
  ?size=20       — Har sahifada nechta element
  ?sort=fieldName,asc   — O'sish tartibida saralash
  ?sort=fieldName,desc  — Kamayish tartibida saralash
